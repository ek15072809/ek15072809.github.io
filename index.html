§ I

About

ek15072809は前衛的かつ実用的な大規模言語モデルの開発を行う個人研究開発者です。 CPU 16GB DRAM 環境での AGI の実現を目標としています。

2.5bit量子化にて最大4.5bit相当の性能を実現するTa量子化や、 MoEモデルのSSDオンデマンドロード、軽量エージェントツールなどについて研究、技術公開をしています。

また、arXiv の cs.CL / cs.LG分野への投稿を目指しています。 推薦していただける分野がありましたら、ご連絡いただけると幸いです。

研究の詳細は Research ページに、 コミットの記録は Commit ページにまとめています。

§ II

Selected Work

01.

Tema_Q LLM

huggingface.co/temaq-org

通常のモデルでは回答が難しいプロンプトに対しても、より自由で有用な応答を生成できる大規模言語モデルです。2025年から公開を続けています。

Open in Hugging Face
02.

Tema_Q-Abliterated

github.com/ek15072809/Tema_Q-Abliterated

大規模言語モデルのAbliterated探査を最大で49倍高速に行うツール。新技術SCAPEによりCPUでの実行も可能となっています。

Open in GitHub
03.

Tema_Q-Agent

github.com/ek15072809/Tema_Q-Agent

ローカルデバイス上での動作を前提としたコーディングエージェントです。 Tqma_Q X6 TaIQ2_Mとの組み合わせで、限られた計算環境下でも 動作する高機能なエージェントツールの構築をが可能です。

Open in GitHub
04.

Swap-MoE

github.com/ek15072809/Swap-MoE

llama.cppに対するMoEモデルのSSDオンデマンドロードの実装です。 SSD 上のエキスパートをオンデマンドで読み込む構成により、 16GB DRAM デバイスで +200B モデルの推論を実現します。

Open in GitHub
05.

TaQuants

huggingface.co/TaQuants

TaQuantsは量子化に対して脆弱なテンソルの特定及び保護による極抵量子化法です。 GPUを有しない低リソース環境において、重要度行列を凌ぐ品質を実現します。 検証モデル及び実行スクリプトの公開を行っています。
